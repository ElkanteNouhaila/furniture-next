# Luxury Touch — Premium Furniture E-commerce

A modern, responsive furniture e-commerce website built to showcase elegant furniture and home décor. Luxury Touch combines a refined visual identity with a smooth shopping experience across desktop and mobile devices.

## Overview

Luxury Touch is a furniture storefront featuring curated product categories, product discovery, a shopping cart, and customer contact options. The interface uses a minimalist design with warm gold accents to reflect the brand's premium identity.

## Features

- **Responsive Design:** Optimized for desktop, tablet, and mobile.
- **Product Categories:** Browse furniture and home décor collections.
- **Shopping Cart:** Add products, update quantities, remove items, and clear the cart.
- **Theme Switching:** Light and dark modes.
- **Contact Page:** Customer inquiry form and contact information.
- **About Page:** Brand story, values, and company presentation.
- **WhatsApp Contact:** Support for product inquiries and order confirmation.
- **Modern Navigation:** Sticky navbar with a translucent background and backdrop blur.

## Tech Stack

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **UI:** React
- **Styling:** Tailwind CSS
- **Icons:** React Icons / Heroicons
- **Package Manager:** pnpm

## Getting Started

### Prerequisites

Install the following:

- Node.js (LTS recommended)
- pnpm

### Installation

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
cd furniture-next
```

Install dependencies:

```bash
pnpm install
```

Start the development server:

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Available Scripts

| Command | Description |
